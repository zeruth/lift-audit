# Lift audit

`reference/` is the original C source of a game engine. `port/src/gen/` is C generated by a
binary lifter from the 32-bit MSVC x86 build of that source, one file per original object
(`cl_input.c` is `reference/src/client/src/cl_input.c` lifted). The port builds and runs, but
some logic diverges from the original. The task is to find where.

Reading the generated code:

- Pointers are 32-bit guest addresses held in `uint32_t`; `RA_U32`/`RA_F32`/`RA_F64(p)` read and
  write memory (`port/src/gen/runtime/rhipper.h`).
- `frame_mem` is a function's guest stack frame; `frame + N` are its slots; `esp - N` is an
  outgoing argument or a local's address.
- x87 float returns go through `ra_x87_stack`/`ra_x87_top`: a function pushes its float result
  there and the caller pops it.
- `sec_data.X` is the global `X`; a struct member gets a suffixed name (`cl_448` is the field of
  `cl` at byte 448, `in_strafe_8` is `in_strafe.state`).
- SSE registers are the `xmm` array. `U_xxxxxxxx` is an unnamed function at that address.
- A variadic call's argument block is built in `va_*` locals; it must be one contiguous block.
